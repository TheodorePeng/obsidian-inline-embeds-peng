# Inline Embeds Peng

## 1.0.5

- Fork identity: Inline Embeds Peng (`inline-embeds-peng`), based on upstream 1.0.4.
- Make list-item blocks, standalone inline embeds, and all styles available without an account.
- Remove account checks, paid-feature notices, and promotional UI from the runtime.
- Preserve default appearance, renderer behavior, original settings isolation, and MIT attribution.
- Adapt unit, real-app, keyboard, and QA regressions to the account-free behavior.
- Include the original MIT notice in generated runtime JavaScript.
- First public distribution through a GitHub Release: <https://github.com/TheodorePeng/obsidian-inline-embeds-peng/releases/tag/1.0.5>, installable and updatable with BRAT.
